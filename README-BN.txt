NOVA — Premium Anime Library

1. Extract this ZIP.
2. Host the folder on an HTTPS static host (such as GitHub Pages) to enable PWA installation and offline caching.
3. Open the HTTPS site in Chrome and choose Install app / Add to Home screen.
4. Open Watching, add a title, then choose Manage Episodes.
5. Tap an episode status to toggle Watched / Not Watched. Use Add Video to store a local copy, Play Video to watch, and the delete icon to remove it.

Browser storage is quota-limited and can be cleared by the browser or device. MP4 with H.264 video and AAC audio is the most compatible format in Android Chrome. Unsupported codecs may show audio with a black screen. This browser-based player is not a full VLC replacement.
